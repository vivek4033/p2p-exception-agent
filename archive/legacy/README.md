# Archived Utilities

These scripts and the illustrative page are retained for historical reference. They are not part of the v1.3 results workflow.

- `build_mvp_dashboard.py` is redirected to `archive/legacy/mvp_dashboard.html`. Use the repository-root `build_dashboard.py` for public results.
- `run_sample.py` writes its deterministic illustrative page under this archive. It is not the live results queue or an AI evaluation.
- `sample_dashboard.html` is the generated sample page. Its old prioritization used full case cycle time, including events after the decision point; do not use it as a decision-time priority result.
- `verify_fast.py` and `diagnose_value.py` are one-off diagnostics retained for reference.
